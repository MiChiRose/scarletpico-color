# Установка прошивки ScarletPico

[← О проекте](../README.md) · [Схема и распиновка](PINOUT.md)

Инструкция для **RP2040-Zero** и прошивки **2.2.8**. Образ RP2350 не подходит.
Нужны компьютер и USB-кабель с передачей данных, не только зарядкой.

## Скачать файл

Открыть [ScarletPico-v2_2_8-RP2040-LIBRARY-PAGING.uf2](../firmware/releases/2026-10-22-rp2040-library-paging/ScarletPico-v2_2_8-RP2040-LIBRARY-PAGING.uf2)
и скачать бинарный файл кнопкой загрузки raw-файла на GitHub.
Не сохранять HTML-страницу под расширением `.uf2`.

Размер — **478 720 байт**, SHA256:

```text
8e0a7d0b898812ad8b3b899caf189172cc4307b4b35bfc42225050b49bbe60ba
```

## Убрать второе питание

Выключить приставку. Отключить аккумулятор / внешнее питание сборки перед
подключением USB к RP2040. В прототипе нет проверенного автоматического
выбора USB/аккумулятора: одного положения выключателя может не хватить,
чтобы исключить обратные пути питания. Не подключать одновременно USB
платы, зарядный USB-C и выход повышайки.

Прошивка загружается через USB-C **на самой RP2040-Zero**.
Выносной разъём корпуса идёт к зарядке, а не к USB-данным MCU.

## Войти в загрузчик

1. Зажать **BOOT / BOOTSEL** на процессорной плате.
2. Не отпуская кнопку, подключить плату к компьютеру.
3. После появления диска **RPI-RP2** отпустить кнопку.
4. Скопировать на этот диск один нужный `.uf2`.
5. Дождаться конца копирования. Плата перезапустится, диск исчезнет.

Это штатный механизм UF2 из
[документации Raspberry Pi](https://www.raspberrypi.com/documentation/microcontrollers/c_sdk.html).
BOOTSEL находится в ROM микроконтроллера; заменять загрузчик не требуется.

Если диска нет, проверить кабель, другой USB-порт и зажатие BOOT именно
при подключении. Не копировать UF2 на microSD. Не запускать `flash_nuke`
для обычного обновления: полное стирание flash не нужно.

## Подготовить microSD

Используется первая MBR-партиция FAT16/FAT32. Уже работающую карту
**не форматировать ради обновления**.

```text
microSD/
├── roms/      поддерживаемые файлы .gb и .gbc
└── saves/     прошивка создаёт каталог при необходимости
```

Не удалять существующие сохранения; перед экспериментами полезна их копия.
ROM-ы не поставляются с проектом. После копирования безопасно извлечь карту.

## Первая проверка

Отключить USB компьютера и только затем восстановить штатное питание.

- Заставка опускается в центр, затем открывается читаемая библиотека.
- Вверх/вниз или Select выбирают игру; A/Start запускают её.
- Список не обрезан после 32 игр; работают переходы между блоками,
  удержание вверх/вниз и запуск ROM из конца списка.
- Вправо открывает настройки библиотеки, B обновляет список.
- Удержание Start + Select около 1,5 с в игре открывает паузу.
- Работают звук, громкость, сохранение и загрузка состояния.
- Батарейка и напряжение видны вверху; во время игры — в правой полосе,
  без перекрытия изображения. Показание соответствует аккумулятору,
  а не выходу повышайки 5 В.

Напряжение приблизительное. Значок — не точный процент остатка. Молния
зарядки не выводится: статусы TP4056 сейчас к MCU не подключены.

## Откат

Повторить BOOTSEL с одним из файлов:

- [2.2.7 до исправления каталога](../firmware/releases/2026-10-20-rp2040-ui-polish/ScarletPico-v2_2_7-RP2040-UI-POLISH.uf2).
- [2.2.6 с GP29-батарейкой](../firmware/releases/2026-10-20-rp2040-legacy222-battery/ScarletPico-v2_2_6-RP2040-LEGACY222-GP29.uf2).
- [2.2.2, проверенная на устройстве](../firmware/releases/2026-10-07-rp2040-native-menu/01-ScarletPico-v2_2_2-RP2040-ROLLBACK.uf2).

Обновление не требует менять делитель или конденсатор. Не стирать сохранения.
При проблеме записать версию UF2, симптом и результат отката, прежде чем
менять одновременно код и пайку.
