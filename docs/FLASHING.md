# Установка прошивки ScarletPico

## Текущая сборка: RP2350 · 3.6.3

Только **Waveshare RP2350-USB-A с разводкой ScarletPico и кнопками через
74HC165**. Не прошивать этим файлом RP2040. Одинаковый процессор на другой
плате не означает одинаковую разводку экрана, SD и кнопок.

**[Скачать UF2 3.6.3](../firmware/releases/2026-11-18-rp2350-3.6.3/ScarletPico-v3_6_3-RP2350.uf2)**
— открыть файл на GitHub и нажать **Download raw file**, а не сохранять
HTML-страницу. Размер: **473 600 байт**.

```text
SHA-256: 66577c0a8a363faa4b5ddea6b08e0b8a6e8b341434a51fdb3d17699e353141f5
```

3.6.3 собрана и прошла программные проверки; физическая проверка этой
версии пока не выполнена. [Изменения и отчёты](../firmware/releases/2026-11-18-rp2350-3.6.3/README-RU.md).

### Перед подключением

- Выйти из игры через меню паузы и дождаться успешного сохранения.
- Выключить приставку, отключить аккумуляторное питание процессорной платы.
  До проверки развязки не объединять USB-питание компьютера и другой источник 5 В.
- Использовать штатный USB-C **на RP2350** и кабель с передачей данных.
  Внешний разъём корпуса пригоден только после проверки линий данных и питания.
  Площадки снятого USB-A этой платы не заменяют штатный USB для BOOTSEL.
- Сделать копию сохранений с карты. Полное стирание flash и форматирование
  microSD для обычного обновления не нужны.

### Записать прошивку

1. Зажать **BOOT / BOOTSEL** на плате.
2. Не отпуская кнопку, подключить USB к компьютеру.
3. Когда появится накопитель **RP2350**, отпустить кнопку.
4. Скопировать один файл `ScarletPico-v3_6_3-RP2350.uf2` на этот накопитель.
5. Дождаться окончания копирования: плата перезапустится, диск исчезнет.
6. Отсоединить USB перед восстановлением штатного питания сборки.

**UF2 кладётся на диск загрузчика, не на карту с играми.** Плата может быть
прошита без microSD; карту вставлять только при выключенном питании.
Без карты настройки и встроенные темы должны открываться.

### Проверить после обновления

- Главное меню: **Игры / Настройки / Темы / Продолжить**; работают кнопки.
- С картой: открываются библиотека, обложки при наличии файлов и знакомая игра.
- В игре: Start + Select открывает паузу; проверить звук и сохранение.

Если дисплей чёрный, но есть звук, не прошивать бесконечно разные версии:
при выключенном питании проверить соединения дисплея, особенно VCC и GND.
При отсутствии USB-диска сначала проверить кабель, BOOTSEL и USB-порт.

### Откат и карта

Для отката нужен ранее работавший **RP2350-образ с той же разводкой**.
RP2040 2.2.8 для этого не подходит. Обновление не должно удалять файлы карты,
но совместимость снимков состояния между произвольными версиями не гарантируется.

## Убрать второе питание

Выключить приставку. Отключить аккумулятор / внешнее питание сборки перед
подключением USB к RP2040. В прототипе нет проверенного автоматического
выбора USB/аккумулятора: одного положения выключателя может не хватить,
чтобы исключить обратные пути питания. Не подключать одновременно USB
платы, зарядный USB-C и выход повышайки.

Прошивка загружается через USB-C **на самой RP2040-Zero**.
Выносной разъём корпуса идёт к зарядке, а не к USB-данным MCU.

## Войти в загрузчик

1. Зажать **BOOT / BOOTSEL** на процессорной плате.
2. Не отпуская кнопку, подключить плату к компьютеру.
3. После появления диска **RPI-RP2** отпустить кнопку.
4. Скопировать на этот диск один нужный `.uf2`.
5. Дождаться конца копирования. Плата перезапустится, диск исчезнет.

Это штатный механизм UF2 из
[документации Raspberry Pi](https://www.raspberrypi.com/documentation/microcontrollers/c_sdk.html).
BOOTSEL находится в ROM микроконтроллера; заменять загрузчик не требуется.

Если диска нет, проверить кабель, другой USB-порт и зажатие BOOT именно
при подключении. Не копировать UF2 на microSD. Не запускать `flash_nuke`
для обычного обновления: полное стирание flash не нужно.

## Подготовить microSD

Используется первая MBR-партиция FAT16/FAT32. Уже работающую карту
**не форматировать ради обновления**.

```text
microSD/
├── roms/      поддерживаемые файлы .gb и .gbc
└── saves/     прошивка создаёт каталог при необходимости
```

Не удалять существующие сохранения; перед экспериментами полезна их копия.
ROM-ы не поставляются с проектом. После копирования безопасно извлечь карту.

## Первая проверка

Отключить USB компьютера и только затем восстановить штатное питание.

- Заставка опускается в центр, затем открывается читаемая библиотека.
- Вверх/вниз или Select выбирают игру; A/Start запускают её.
- Список не обрезан после 32 игр; работают переходы между блоками,
  удержание вверх/вниз и запуск ROM из конца списка.
- Вправо открывает настройки библиотеки, B обновляет список.
- Удержание Start + Select около 1,5 с в игре открывает паузу.
- Работают звук, громкость, сохранение и загрузка состояния.
- Батарейка и напряжение видны вверху; во время игры — в правой полосе,
  без перекрытия изображения. Показание соответствует аккумулятору,
  а не выходу повышайки 5 В.

Напряжение приблизительное. Значок — не точный процент остатка. Молния
зарядки не выводится: статусы TP4056 сейчас к MCU не подключены.
