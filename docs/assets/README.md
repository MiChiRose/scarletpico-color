# Иллюстрации проекта

Изображения в README воспроизводят существующую айдентику и геометрию,
не предлагают новую конструкцию или неподтверждённый внешний вид платы.

| Файлы | Источник |
|---|---|
| `scarletpico-banner.png`, `boot-screen.png`, `boot.gif` | Выполнение настоящих ARM-функций заставки из закреплённой 2.2.7; моделируется только периферийный вывод LCD. Баннер — увеличенный без сглаживания кроп последнего кадра. |
| `case-front.png`, `case-inside.png` | Последняя передняя часть R3 со стойками LCD 3 мм; реальные STL кнопок. Экран — условный выключенный габарит, не придуманная игровая сцена. |
| `case-rear-options.png` | Сравнение реальной цельной R2 и трёх реальных экспортов R3 в их печатных ориентациях. Это не изображение взаимозаменяемых деталей. |
| `wiring-*.svg`, `wiring-*.png` | Монтажные схемы по `docs/PINOUT.md`, не физическая раскладка контактов/PCB. SVG редактируемые, PNG — для стабильного показа в GitHub. |
| `cad-provenance.json` | SHA256 исходных STL; печатные файлы не изменяются рендерером. |

Генераторы находятся в `tools/`:

```sh
# ARM-код + Pillow; JIT Unicorn на macOS требует разрешённого окружения:
python tools/capture_boot_art.py
# numpy + Pillow; только чтение STL:
python tools/render_case_art.py
# Стандартный Python, исходные SVG:
python tools/render_wiring_art.py
# Сгенерировать PNG из SVG (Node.js + sharp):
node tools/rasterize_wiring.cjs
```

ARM-зависимости — `requirements-firmware-test.txt`; Pillow для изображений
ставится отдельно. Для рендера корпуса нужны также numpy и установленный
Arial либо DejaVu Sans. Не использовать эти картинки как размерный чертёж.
