ScarletPico Color — личный DIY-проект: настоящая крестовина, физические
кнопки, цветной экран, динамик, microSD и собственный печатный корпус.
Внутри — **микроконтроллер**, не Linux-компьютер. Проект вырос из ручной
пайки, примерок корпуса и желания сделать удобную приставку для любимых игр.

**Текущая платформа — Waveshare RP2350-USB-A с 74HC165.** Переход с RP2040
уже состоялся. Поддерживаются GB/GBC; NES, SNES и GBA в эту прошивку не входят.
Совместимость и скорость зависят от игры: обещания «весь каталог в 60 FPS» нет.

## Что умеет приставка

| Играть | Настроить | Сделать паузу |
|---|---|---|
| GB/GBC с microSD; каталог подгружается порциями | Русский / English, громкость и яркость | Пять ручных слотов снимков состояния |
| Обложки, недавние игры и избранное в начале списка | Scarlet / Ice / DMG, акценты и обои | Автоматическое продолжение при доступном сохранении |
| Отдельные профили громкости, масштаба и CPU для игр | Вид библиотеки, звуки меню и анимация | Заставки, сон дисплея и программная перезагрузка |

- **Выделение не только цветом:** активная плитка увеличивается и получает
  контрастную рамку — выбор проще различить при нарушениях цветовосприятия.
- **Без карты меню не исчезает:** настройки и встроенные темы доступны;
  разделы, которым нужны файлы, сообщают об их отсутствии и позволяют вернуться.
- **Аккумулятор на виду:** скруглённый индикатор и напряжение. При устойчивом
  низком напряжении — предупреждение и короткий звук с учётом громкости.
- **Lofi Radio без сети:** WAV с карты и подготовленные анимации. Название
  «radio» не означает интернет-радио, Wi-Fi для этой функции не нужен.

## Быстрый старт

1. **Проверить плату и разводку.** Этот UF2 — только для текущей сборки
   **RP2350-USB-A + 74HC165**, не для произвольной платы RP2350 или RP2040.
2. **[Установить 3.6.3](docs/FLASHING.md)** через BOOTSEL и USB с передачей данных.
   UF2 копируется на диск загрузчика **RP2350**, не на microSD.
3. На выключенной приставке вставить FAT16/FAT32-карту с собственными
   `.gb` / `.gbc` в `/roms`. Работающую карту ради обновления не форматировать.
4. Открыть **Игры → Все игры**, выбрать игру и нажать **A**.
5. Для паузы удерживать **Start + Select** около 1,5 секунды.

### Основные кнопки

| Где | Действие |
|---|---|
| Главное меню | Крестовина — выбор; **A / Start** — открыть |
| Карусель игр | **← / →** — перелистывание; **A** — запуск |
| Библиотека | **Select** — смена вида; **Start** — избранное и параметры игры; **B** — назад |
| Настройки | **↑ / ↓** — пункт; **← / →** — значение; **A** — открыть; **B** — назад и сохранить |
| Во время игры | Удерживать **Start + Select** — пауза |
| Сон / обычная заставка | Любая кнопка — пробуждение / возврат |

**Хотите Zelda в начале списка?** Выделить её → **Start → Избранное → Да**.
Игра останется в общей коллекции, но поднимется в начало; также появится
в **Игры → Избранное**. [Полное руководство →](docs/USAGE.md)

## Тихий режим: Lofi Radio

Положить музыку в **`/lofiplayer/music`** и удерживать **Select 1,5 с в главном
меню**. В 3.6.3 без непустых WAV-файлов или без microSD не происходит ничего:
скрытая функция не открывает пустой экран и не показывает ошибку.

| Кнопки | Действие |
|---|---|
| **A / Start** | Пауза / продолжение после отпускания кнопки |
| **← / →** | Предыдущий / следующий трек |
| **↑ / ↓** | Громкость |
| Удерживать **A** + **← / →** | Предыдущая / следующая анимированная сцена |
| **B** | Показать / скрыть подсказки |
| Удерживать **Select + Start** | Выйти из Lofi |

Нужен **PCM WAV: 32 000 Гц, 16 бит, стерео**. Анимации — подготовленные
`.lfi` в `/lofiplayer/animation`, не обычные GIF. Музыка и медиапакет не
вшиты в UF2 и не поставляются вместе с ним. [Форматы и файлы →](docs/USAGE.md#файлы-на-microsd)

## Внутри корпуса

| Узел | Текущая сборка |
|---|---|
| Процессорная плата | Waveshare RP2350-USB-A, RP2350, 2 МБ flash |
| Экран | SPI TFT ST7796, 3,5″, 480 × 320 в горизонтальной ориентации |
| Кнопки | D-pad, A/B, Start/Select через 74HC165 |
| Хранилище | microSD; общая SPI-шина с дисплеем |
| Аудио | I2S MAX98357A и динамик |
| Питание | Одноэлементный Li-ion/LiPo, зарядка с защитой и питание сборки |
| Монтаж | Две макетные платы 50 × 70 мм, кнопки отдельно |
| Корпус | 3D-печатный; для текущей сборки выбрана цельная задняя крышка |

<details>
<summary>Корпус и история конструкции</summary>

<img src="docs/assets/case-front.png" alt="Исторический CAD-рендер передней части корпуса R3" width="400">

Исторический рендер R3 из реальных STL, **не фотография текущей сборки**.
[Архив моделей](hardware/case/README.md) содержит и цельные, и секционные
варианты; не смешивать детали разных ревизий без проверки совместимости.
Старый список STL не означает, что всё надо перепечатать.

</details>

**Важно для повторной сборки:** [старая распиновка](docs/PINOUT.md) описывает
RP2040; её нельзя автоматически переносить на RP2350. Питание USB и
аккумулятора требует согласованной развязки. Зарядный разъём корпуса не
становится разъёмом прошивки без подключения линий данных. Во время работы
не вынимать и не вставлять microSD.
