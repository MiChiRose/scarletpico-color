# Product

## Register

product

## Users

People building and using a low-cost DIY monoblock console based on a Raspberry Pi RP2040/RP2350 board. They interact through a 480×320 color display and physical controls in one rigid enclosure, often in short play sessions.

## Product Purpose

ScarletPico Color is a focused Game Boy and Game Boy Color console: switch it on, choose a ROM from microSD, play it reliably, preserve progress, and return later without desktop-emulator complexity. The desktop build validates the software interaction before the physical hardware is assembled.

## Brand Personality

Nostalgic, playful, precise. It should recall late-1980s and 1990s handheld electronics while remaining an original ScarletPico product.

## Anti-references

Do not copy Nintendo trademarks, boot graphics, or audio. Avoid generic black-and-white file browsers, modern dashboard chrome, touch-first controls, decorative glass effects, and interfaces that hide the limited physical-button model.

## Design Principles

- Behave like dedicated hardware, not a web page.
- Make the primary action obvious with only directional controls and two face buttons.
- Preserve progress safely and visibly.
- Use nostalgia as interaction texture, not as copied intellectual property.
- Keep desktop and Pico behavior structurally equivalent even though the desktop shell is only a simulator.

## Accessibility & Inclusion

Maintain readable contrast on the simulated reflective LCD palette, never rely on color alone for selection or status, provide clear keyboard focus, and respect reduced-motion preferences by shortening the boot sequence without removing state information.
