# ScarletPico 3.6.3 — RP2350

Дополнительные проверки доступности необязательных файлов на microSD.
Отсутствующие, пустые и недоступные каталоги обрабатываются без перехода
в недоступный режим. Проверка не пишет на карту и не затрагивает буферы
обложек/видео. Остальные функции линии 3.6.2 сохранены.

Сборка предназначена для Waveshare RP2350-USB-A. Автоматической записи
на приставку в рамках этого изменения нет; аппаратная проверка отдельно.

## Проверки

- Сборка RP2350 завершена; host suite пройден.
- ARM-тест необязательных медиа и обработки недоступных файлов — PASS.
- ARM-тест системного меню без SD — PASS.
- ARM-тест обложки «Продолжить» и отсутствия чтения SD при анимации — PASS
  (лимит эмулятора 400 млн инструкций).
- Отчёты ARM-тестов рядом с UF2 привязаны к SHA-256 ELF.

SHA-256 UF2: `66577c0a8a363faa4b5ddea6b08e0b8a6e8b341434a51fdb3d17699e353141f5`
