# ScarletPico Color v3.0 — RP2350-Zero, тестовая сборка

Наш интерфейс поверх исходников другого агента. Приставка автоматически **не перепрошивалась**.

## Файлы

- `02-ScarletPico-v3_0-RP2350-OUR-MENU.uf2` — новая прошивка.
- `01-RP2350-NATIVE-B-ROLLBACK.uf2` — точная копия исходной сборки B другого агента, без нашего звука, паузы и снимков. Это не дамп установленной сейчас прошивки.
- `ScarletPico-v3_0-RP2350-source.zip` — переносимый исходный проект, включая наш интерфейс, звук и тесты; без ROM, SDK и компилятора.
- `build-audit.json` — параметры сборки, контрольные суммы и список неизменённых функций.
- `VALIDATION.md` — результаты компьютерных проверок и их ограничения.

## Что объединено

От другого агента: ядро Peanut-GB с GB/GBC, выполнение горячих функций из RAM,
тройная буферизация, второй процессорный поток и SPI/DMA-вывод на ST7796.
Заголовок ядра и тела основных функций вывода сверены с исходным ZIP — без изменений.

От нашего проекта: оформление вертикального списка, обновление только изменившихся
строк, загрузочный логотип и звук, спиннер, экран ошибки microSD, пауза,
настройки яркости/громкости, «About device» и пять слотов снимков на каждую игру.
Звук — наш прежний APU, I2S через GP11/12/13 для MAX98357A; отдельные DMA-каналы
и прерывание не пересекаются с выводом дисплея.

Перенесено наше исправление выбора **первого раздела MBR**: устаревшие FAT-данные
в секторе 0 не должны скрывать настоящий раздел карты. Добавлены проверки размера
и заголовка ROM, безопасный выход при фатальной ошибке ядра. Отладочный USB-вывод
не должен тормозить игру, если Mac перестаёт читать журнал.

## Почему профиль B

| Входная сборка | CPU | Запрос SPI дисплея | Изображение игры |
|---|---:|---:|---:|
| A | 200 МГц | 50 МГц | 240 × 216 |
| **B — основа новой** | **200 МГц** | **100 МГц** | **320 × 288** |
| C | 240 МГц | 120 МГц | 320 × 288 |
| D | 200 МГц | 100 МГц | 240 × 216 |

B сохраняет крупную картинку без дополнительного разгона до 240 МГц.
Родные 160 × 144 увеличиваются ровно ×2; дисплей 480 × 320. Игра по центру,
полосы чёрные. Это 320 × 288, **не** прежнее растяжение 356 × 320.
Внизу — одно значение FPS завершённых передач изображения, без счётчика EMU.
Запрос SD SPI сохранён: 12 МГц; фактическую частоту выбирает делитель SPI.

**200 МГц — разгон RP2350, а 100 МГц SPI — экспериментальный режим дисплея.**
Эти параметры взяты из B, но их стабильность на конкретной пайке не подтверждена.
При артефактах или зависаниях нужен откат/снижение частоты, а не обещание «безопасного максимума».

## Управление

- Вверх/вниз или Select — выбор; A/Start — запуск игры или открытие папки.
- Вправо — настройки; B — возврат из папки либо обновление списка.
- Удерживать Start + Select около 1,5 секунды — пауза: Resume / Save state /
  Load state / Settings / Return to library. Для выхода есть подтверждение.
- В паузе можно изменить громкость/яркость и продолжить **ту же** игру.
- Громкость 0–100%, шаг 10%, по умолчанию 50%. Яркость 10–100%, шаг 10%, по умолчанию 100%.
- Интерфейс английский. Настройки сохраняются в отдельном секторе flash.

**Отличие от старой прошивки:** CPU сейчас фиксирован на 200 МГц,
пункт показывает частоту, но не переключает 125/170/200. Переключение не переносилось,
чтобы не менять тайминги новой базы. «About device» показывает версию, плату,
частоту, размер игры и запрошенную скорость дисплея.

## microSD и сохранения

Перед тестом скопируй карту на Mac как резервную копию. Подходит карта с первым
разделом MBR FAT16/FAT32 и папкой `/roms` для `.gb`/`.gbc`; корректную существующую
карту заново форматировать не нужно. Бесраздельная «superfloppy» этой сборкой не монтируется.
Список поддерживает до 192 файлов/папок в текущей директории.

Обычные игровые сохранения новой базы: `/scarlet2350/saves/<полное имя ROM>.sav`
и рядом `.rtc`. Снимки: `/scarlet2350/states/<CRC всего ROM>-<слот>a/b.sps`.
Пять слотов на игру; каждый снимок включает **всю** игру и все её внутренние профили.
При перезаписи хранится предыдущая исправная копия, загрузка проверяет контрольные суммы.
Не выключай питание во время записи. Эти меры не гарантируют сохранность файловой системы
при внезапном отключении питания.

Старые файлы не удаляются и автоматически не переносятся. Снимки RP2040 несовместимы
с RP2350; если нужны старые `.sav`, их перенос надо сделать отдельно с резервной копией.

Предел кэша ROM в 4-МиБ flash: **3,5 МиБ**, то есть стандартные ROM до **2 МиБ**.
Прежний стриминг больших 4/8-МиБ ROM не переносился, поскольку здесь оставлен загрузчик
новой базы. Снимки работают с RAM картриджа до 64 КиБ. Для игр с RAM 128 КиБ игра
работает, но снимок не помещается в переиспользуемые буферы и выдаёт ошибку памяти.

## Как установить с Mac

1. Сохрани прогресс и сделай резервную копию карты. Отключи USB и питание от аккумулятора.
2. Зажми BOOT на **RP2350-Zero**, подключи USB к Mac и отпусти BOOT.
3. Открой появившийся USB-диск загрузчика и скопируй на него **только**
   `02-ScarletPico-v3_0-RP2350-OUR-MENU.uf2`, не на microSD.
4. Диск загрузчика исчезнет, плата перезапустится. Вставляй/вынимай microSD при выключенном питании.

Откат: таким же способом скопируй `01-RP2350-NATIVE-B-ROLLBACK.uf2`.
Прошивки старого RP2040 не используй для RP2350. Драйвер для переноса UF2 на Mac не нужен.

## Исходники и проверка

Рабочие исходники: `firmware/imported/scarletpico-rp2350-source/` плюс общие модули
`firmware/ui-addon`, `firmware/features-addon`, APU и PIO. Инструкции пересборки:
`firmware/imported/scarletpico-rp2350-source/MERGE.md`.
Сборка: Pico SDK 2.3.1, ARM GCC 14.3.1, picotool 2.3.0. Входный проект использовал
SDK 2.3.0; наша сборка использует 2.3.1 с сохранением нативного ядра и функций рендера.

Компьютерные тесты не измеряют физический FPS, качество звука, электрические тайминги
карты/дисплея и устойчивость разгона. После ручной установки эти пункты нужно проверить
на приставке. Эта сборка пока тестовая.
