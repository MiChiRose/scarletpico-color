# ScarletPico Color 2.2.3 — тестовая сборка RP2040

Это полноценная пересборка приложения под **RP2040-Zero / Cortex-M0+**,
а не переименование файла или замена идентификатора в RP2350 UF2.
Заводской USB-загрузчик ROM не меняется. Новый UF2 имеет family ID `e48bff56`,
обычный SDK boot2 и стартовый вектор RP2040.

Подключённая 7 октября плата проверена чтением заводской ROM: magic
`0x0301754d`, версия 3, то есть RP2040. Она не может выполнять приложение RP2350.

## Файлы

- `02-ScarletPico-v2_2_3-RP2040-NATIVE-TEST.uf2` — новая тестовая сборка.
- `01-ScarletPico-v2_2_2-RP2040-ROLLBACK.uf2` — точная копия предыдущей 2.2.2
  SHADOW FAST, не дамп текущего содержимого платы.
- `ScarletPico-v2_2_3-RP2040-source.zip` — исходники этой сборки и сценарий пересборки.
- `build-audit.json`, `VALIDATION.md` — контрольные суммы, лимиты и результаты проверок.

**Автоматической перепрошивки не было.**

## Установка с Mac

1. Сохрани прогресс текущей игры и выключи приставку.
2. Подключи плату USB-кабелем с передачей данных, удерживая её **BOOT**.
   После появления диска `RPI-RP2` отпусти BOOT. Если диск уже открыт, повторный
   вход в BOOT необязателен.
3. Скопируй на `RPI-RP2` только файл `02-ScarletPico-v2_2_3-RP2040-NATIVE-TEST.uf2`.
   Не на microSD и не внутрь папки на диске. Распаковывать UF2 не нужно.
4. После полной передачи плата обычно перезапускается и диск исчезает.
   На дисплее должно появиться наше меню; в **About device** — `2.2.3 TEST`, `RP2040`.
5. Если диск остался, не пытайся менять его `INFO_UF2.TXT` или family ID файла.
   Сообщи результат и состояние экрана: успешное копирование ещё не подтверждает запуск.

Для отката повтори те же действия с `01-ScarletPico-v2_2_2-RP2040-ROLLBACK.uf2`.
Дополнительные драйверы или библиотеки на Mac для копирования UF2 не нужны.

## Что сохранено и адаптировано

- Ядро Peanut-GB-CGB из присланных исходников другого агента не изменено.
  Тот же LCD-драйвер: x2, RGB565, DMA-передача строк, вывод игры **320 × 288**
  на панели 480 × 320, чёрные поля; индикатор FPS внизу.
- Наши меню, оформление, заставка со звуком, About device, экраны ошибок microSD,
  загрузочный спиннер, пауза и настройки. При выборе соседней игры весь экран
  повторно не очищается. Интерфейс английский.
- Удержание **Start + Select 1,5 с** открывает паузу; настройки громкости и яркости
  доступны без выхода из игры. Пять слотов снимков состояния, две проверяемые
  поколения каждого слота. A подтверждает, B возвращает.
- Громкость 0–100 с шагом 10, по умолчанию 50%; яркость 10–100 с шагом 10.
- CPU **200 МГц**, запрос LCD SPI **100 МГц**, запрос SD SPI **12 МГц**.
  Это экспериментальные повышенные частоты, не обещание стабильности для любой
  платы и проводки. CPU здесь фиксирован: старый выбор 125/170/200 не перенесён.
- Под RP2040 звук использует **DMA IRQ1**, SD — IRQ0. MAX98357A: GP11 BCLK,
  GP12 LRCLK, GP13 DIN. Пины дисплея/SD/кнопок не переставлялись.
- В памяти два кадровых буфера вместо трёх; занятую дисплеем картинку эмулятор
  не перезаписывает и не ждёт освобождения буфера, а пропускает показ кадра.

## Ограничения относительно старой 2.2.2

У RP2040 264 КиБ SRAM. Для этой полностью исходной сборки уменьшены список до
**64 записей на папку** и RAM картриджа до **32 КиБ**. Избыточная RAM отклоняется
с сообщением, а не записывается за пределы буфера. Снимок максимального размера
занимает 83036 байт и помещается в остановленные кадровые буферы размером 92160 байт.

При стандартной flash 2 МиБ под ROM-кэш осталось 1,5 МиБ, поэтому максимальный
обычный размер ROM — **1 МиБ**. **Постраничное чтение больших ROM из старой 2.2.2
пока не перенесено.** Zelda Link's Awakening, предоставленный Aladdin и Pac-Man
помещаются; Pokemon Crystal размером 2 МиБ — нет. Для больших игр оставлена 2.2.2.

Картинка 320 × 288, а не прежние 356 × 320. Это исходный x2-конвейер другого агента;
изменение не является гарантией повышения FPS на RP2040.

Новые обычные сохранения: `/scarlet2040/saves/<имя-ROM>.sav` и `.rtc`.
Снимки: `/scarlet2040/states/`, формат `20400003` с CRC полного ROM и содержимого.
**Снимки старой 2.2.2 несовместимы; автоматического переноса обычных сохранений
тоже нет.** Старые файлы не удаляются. Не форматируй карту ради этой версии.
Игры по-прежнему размещаются в `/roms` на рабочей FAT-карте.

## Проверки и исходники

Пройдены сборка ARMv6-M, проверки UF2 и памяти, тесты меню/паузы/звука именно
собранного ARM-кода, проверки сохранений и SD-разделов. Ядро с локальными Zelda,
Aladdin и Pac-Man прошло по 1800 кадров с санитайзерами на компьютере.
**Физические FPS, звук, стабильность повышенных частот и успешная установка
на эту консоль пока не проверены.**

Для сборки нужны Pico SDK, ARM GCC, CMake/Ninja, Python и pioasm/picotool.
Из корня распакованного проекта:

```sh
python3 firmware/tools/build_rp2040_native.py --sdk /path/to/pico-sdk --toolchain /path/to/arm-gcc --picotool /path/to/picotool --pioasm-dir /path/to/pioasm/lib/cmake/pioasm --rollback /path/to/old-2.2.2.uf2
```

Не удаляй соседнюю папку `scarletpico-rp2350-source`: порт использует её неизменённые
ядро, драйвер LCD и библиотеку SD. SDK, toolchain и коммерческие ROM в архив не включены.
