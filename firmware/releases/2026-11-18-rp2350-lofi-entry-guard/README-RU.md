# ScarletPico 3.6.3 — скрытый вход в Lofi только при наличии музыки

Удержание Select 1,5 секунды в главном меню проверяет наличие хотя бы
одного непустого WAV-файла в `/lofiplayer/music`. Это существующий путь
плеера; папка не переименована в `audio`, переносить музыку не нужно.

Без SD, при недоступной/отсутствующей/пустой папке или без таких WAV
главное меню остаётся на месте: нет сообщения, экрана радио и перерисовки
меню. Каталоги, файлы с именем на точку (включая `._` от macOS), пустые
файлы и другие расширения не считаются музыкой. Регистр `.WAV` не важен.
Содержимое WAV, как и раньше, проверяется при запуске воспроизведения;
наличие непустого файла с расширением WAV не гарантирует корректный PCM.

Проверка выполняется один раз за удержание, ограничена 4096 записями
каталога и закрывает открытый каталог. Повторное удержание повторяет
проверку; постоянного отрицательного кеша нет. Проверка не использует
буферы обложек/видео и не пишет на SD. Остальные функции 3.6.2 сохранены.

Сборка предназначена для Waveshare RP2350-USB-A. Автоматической записи
на приставку в рамках этого изменения нет; аппаратная проверка отдельно.

## Проверки

- Сборка RP2350 завершена; host suite пройден.
- ARM-тест Lofi: воспроизведение, переключение сцен, ошибки файлов,
  проверка доступности, одно сканирование за удержание, повторная проверка
  после отпускания и возвращение к обычной навигации — PASS.
- ARM-тест системного меню без SD — PASS.
- ARM-тест обложки «Продолжить» и отсутствия чтения SD при анимации — PASS
  (лимит эмулятора 400 млн инструкций).
- Отчёты ARM-тестов рядом с UF2 привязаны к SHA-256 ELF.
