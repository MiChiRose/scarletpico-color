# Проверки 2.2.8

**Проверка пользователем, 22.10.2026:** после установки итогового UF2
пользователь сообщил: «Всё работает». Отдельной детализированной матрицы
аппаратных проверок нет. Поля `hardware_tested: false` в автоматических
отчётах ниже описывают компьютерный прогон, а не опровергают этот отзыв.

Это программная проверка реальных Cortex-M0+ инструкций итогового образа
через Unicorn, не физический тест приставки и не измерение её FPS.
В тестах моделируются SD/FatFs I/O и LCD-периферия; код каталога, сортировка,
новый UI, старый шрифт, мосты ввода и GP29-батарейка выполняются как ARM-код.

## Каталог и ввод

- Полный обход вперёд, назад и по кругу: 0, 1, 7, 27, 28, 29, 32, 47,
  56, 57 и 128 ROM; случайный исходный порядок файлов.
- 1000 ROM: верные первые 28 глобальной сортировки, общий счётчик 1000,
  читаются заголовки только текущего блока.
- На этапе проверки сканера, до извлечения microSD из компьютера,
  промежуточный образ прошёл обход всех **47 ROM** пользовательской карты
  в обоих направлениях, без изменения файлов. В финальном прогоне карта
  уже не была смонтирована; повторный тест 47 записей был синтетическим.
- Рескан после игры сохраняет блок, выбор и данные записи (имя, размер,
  сигнатура, статус). B возвращает к первому блоку.
- Проверены настоящий мост главного цикла и отдельный путь автоповтора:
  граница обрабатывается один раз, регистры/стек/флаги сохранены.
- Вправо по-прежнему вызывает старые настройки. GP29 опрашивается через
  прежнюю обёртку ввода, а не обходится новым обработчиком.

## Ошибки и отображение

- Нет карты, нет `/roms`, ошибка чтения каталога или его закрытия: старый
  список очищается, устаревшие записи не остаются доступными для запуска.
- Статусы плохого заголовка/размера, неподдерживаемого MBC и ошибки чтения
  сохранены. Проверены UTF-8 имена, регистр расширений, длина имени 255 байт.
- `._…`, скрытые/системные файлы, подкаталоги и архивы исключаются.
- Реальный рендер RU/EN, счётчик 29 / 47 и границы экранных страниц:
  частичная перерисовка побитно совпадает с полной. В покое перерисовки нет.

## Память и неизменность базы

- Массив остался прежним: 32 × 332 байта; используются только первые 28
  записей. Остальные четыре записи проверяются контрольным заполнением.
- Дополнительная постоянная RAM — **32 байта**. Каталог не выделяет heap.
- Проверен настоящий прежний malloc/free и запуск видео: сохранены режимы
  4/2 бита буфера сравнения, корректный отказ при нехватке памяти и повторное
  освобождение/выделение без роста heap при SRAM 0–100000 байт.
- Аудит проверяет каждый изменённый байт исходного образа по белому списку.
  Из кода главного цикла изменён только четырёхбайтный вызов обработки
  автоповтора; из защищённого блока функций — только строка версии About.
  Код LCD, эмулятора, загрузки ROM, аудио и батарейки не меняется.

Для расширенной аппаратной приёмки полезны запуск ROM после 32-й позиции,
возврат в библиотеку, проверка SRAM/снимков и удержания кнопок на устройстве.
Скорость физической карты и электрические свойства сборки не моделировались.
