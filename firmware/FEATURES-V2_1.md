# ScarletPico Color — Features v2.1 (experimental)

Историческая инструкция v2.1. Текущий сборщик выпускает v2.2; точная копия
исходников v2.1 сохранена в `source-features-v2_1-2026-09-28.tar.gz`.
Её UF2 и старый комплект не изменены.

Небольшое обновление интерфейса поверх Features v2 для **RP2040-Zero, 2 МиБ
flash, ST7796 480×320 и MAX98357A**. Это не UF2 для RP2350.

## Изменения

- `Settings / Настройки` → `About device / Об устройстве`: версия **v2.1**,
  плата, текущая частота CPU, выбранная частота CPU для игр, разрешение дисплея,
  объём flash. Подпись напоминает про GB/GBC и пять слотов снимков на игру.
- Открытие выбранного пункта: **A, Start или вправо**. **B** возвращает в
  настройки и оставляет выделенным «Об устройстве». Удержание B не закрывает
  сразу оба экрана. На странице нет таймера обновления и записи на карту.
- В настройках теперь пять строк. При перемещении курсора перерисовываются
  только прежняя и новая строки; изменение частоты обновляет ещё её подсказку.
  Полная перерисовка остаётся только при смене страницы или языка.
- В игре отображается только **LCD FPS**, на прежнем месте слева, вне картинки.
  EMU FPS больше не выводится. Расчёт LCD FPS и интервал обновления не изменены.

LCD FPS — число **завершённых обновлений игровой картинки в секунду**, а не
физическая частота развёртки панели. Прежняя оптимизация не отправляет
неизменившиеся кадры: на статичной сцене счётчик может показывать 0. Это само
по себе не означает зависание. Показатель EMU больше не рисуется, но внутренняя
логика эмуляции не менялась.

В меню текущая частота — 125 МГц, даже если для следующей игры выбрано 200.
«Об устройстве» различает эти значения. **170 и 200 МГц — разгон RP2040**,
а не его штатные режимы. Выбор профиля и 200 МГц по умолчанию сохранены.

## Что осталось прежним

Ядро эмулятора, игровой рендер/масштабирование, APU, громкость, яркость,
частоты и делители, пять слотов снимков, большие ROM и загрузчик.
Никаких новых библиотек, изображений или постоянных обращений к microSD.

Относительно v2: **+1180 байт кода/констант, +0 байт статической RAM**.
Единственное изменение в видеопотоке — адрес вызова функции текста FPS
(`0x10008a30`, четыре байта). Сама функция рендера и расчёт счётчика побитово
прежние. Сборщик проверяет это и список разрешённых изменений.

Формат настроек, `.sav` и `.sps` сохранён; настройки и снимки v2 не требуется
удалять. Все ограничения больших ROM, снимков и разгона из
[инструкции v2](FEATURES-V2.md) продолжают действовать. Её копия включена в
комплект с UF2 под тем же именем.

## Установка / откат

Сначала сохраните прогресс; для первого теста желательно сделать копию
`/saves` и `/states`. Подключите плату с зажатой **BOOT**, затем скопируйте на
диск **RPI-RP2** файл `02-features-v2_1-EXPERIMENTAL.uf2`.
UF2 копируется **на плату, не на microSD**.

Для возврата к предыдущей v2 аналогично загрузите
`01-features-v2-ROLLBACK.uf2`. Ничего форматировать не нужно.
Проверка на физической консоли ещё требуется; автоматически она не прошивалась.

## Исходники и проверка

Точная сборка использует сохранённую бинарную Fastload-базу и исходники
дополнений, как описано в инструкции v2. `src/` не подменяет точную базу.

```sh
ARM_GCC_BIN=/path/to/arm-gnu/bin python3 firmware/tools/build_features_addon.py
```

Новые файлы: `features-addon/about.c`, `features-addon/hud.c`; дополнены
`settings.c`, карта импортов и сборщик. Версия берётся из `FEATURES_VERSION`.
Результат — `releases/scarletpico-features-v2_1-experimental.uf2` и JSON с SHA-256.
Рабочие файлы и журнал — `build-features-v2_1-addon/` (старые v2 не заменяются).

ARM-тесты исполняют собранный Thumb-код с моделированием периферии:

- пять строк настроек, циклическая навигация, отсутствие полной перерисовки;
- About RU/EN, точные значения текущей/выбранной частоты, вход/возврат,
  отпускание кнопок, отсутствие фоновой перерисовки и лишней записи настроек;
- настоящий вызов нового HUD из исходного видеопотока, независимость LCD от
  EMU, 0–999 FPS, очистка старых цифр, отсутствие пикселей в области игры;
- регрессии звука, часов, Zelda, пяти слотов, ошибок записи и чтения,
  паузы/возврата, больших ROM Pokémon Silver/Crystal и Wario Land 3.

Превью в `build-features-v2_1-addon/previews/` получены из настоящего ARM-рендера,
а не из отдельного макета. Проверки не измеряют физический FPS или качество
сигналов SPI/I2S.
