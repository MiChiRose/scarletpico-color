# ScarletPico Color — Features v2.2.1 (experimental)

Небольшое обновление для **RP2040-Zero / ST7796 / MAX98357A**: изменён только
синтез стартового сигнала и номер версии. База — пользовательская рабочая v2.2.

## Новый звук

Вместо мягких треугольных нот — короткое импульсное «ди-динь»: примерно
1048,6 Гц, затем 2080,5 Гц. Вторая нота начинается через 84 мс. Ориентир —
параметры импульсного канала в [открытой реализации загрузчика SameBoy](https://github.com/LIJI32/SameBoy/blob/master/BootROMs/cgb_boot.asm).
Это самостоятельный синтез, без встроенного Nintendo BIOS или аудиозаписи.
Не побитовая копия оригинала: сглажены атака/границы и укорочено затухание,
чтобы сохранить прежние 400 мс звучания и общую длительность заставки.

Сохранённая громкость применяется прежним микшером. 0% — тишина, настройка
по умолчанию остаётся 50%. `BOOT-CHIME-50.wav` — реальные сэмплы нового ARM-кода
после микшера при 50%, но не запись динамика физической приставки.

Анимация, меню, вывод игры, игровое аудио, частоты, лимиты ROM и сохранения
не меняются. Код заставки после включения не выполняется во время игры;
это обновление **не предназначено для повышения FPS**.
Относительно v2.2: **+44 байта кода/констант, +0 байт статической RAM**.
Подробности прежних функций: [v2.2](FEATURES-V2_2.md), [v2.1](FEATURES-V2_1.md),
[v2](FEATURES-V2.md).

## Загрузка и откат

Сохраните игру. Подключите плату по USB с зажатой BOOT и скопируйте
`02-features-v2_2_1-EXPERIMENTAL.uf2` на диск **RPI-RP2**, не на microSD.
Для возврата к прежнему звуку используйте `01-features-v2_2-ROLLBACK.uf2`.
Карту форматировать не нужно; ROM и сохранения не изменяются.

## Воспроизводимость и проверки

Как прежде, сборка — SHA-проверенная Fastload UF2 плюс C/ASM-дополнения,
а не полная пересборка отличающегося старого дерева `src/`:

```sh
ARM_GCC_BIN=/path/to/arm-gnu/bin python3 firmware/tools/build_features_addon.py
```

Рабочая папка — `build-features-v2_2_1-addon/`. Старые UF2 и архивы исходников
не перезаписываются. Ядро/игровой рендер/APU сверяются побайтно с базой.
ARM-тесты измеряют обе частоты, импульсный тембр и затухание; проверяют
границы PCM, громкость 0/50/100%, таймаут DMA, выключение аудио, Start-пропуск
заставки и вход в игру. Полный прогон также проверяет настройки, профили CPU,
снимки, чтение больших ROM и обработку ошибок. Кадры заставки сравниваются
с v2.2. Результат — `TEST-RESULTS.txt` с SHA тестируемого UF2.

Тесты исполняют ARM-код с моделируемой периферией: физические FPS, качество
звука динамика и реальные задержки microSD ими не измеряются.
