# Декор — выбран вариант 3

В актуальном `01-front-R2.stl` убрана полоска под экраном, исправлено зеркальное чтение внутренней гравировки и добавлен выбранный вариант №3: **по три боковые канавки с каждой стороны**. Число уменьшено с пяти на исходном эскизе до трёх по последнему сообщению пользователя. `selected-side-decor.png` показывает актуальную печатную модель.

`decor-comparison.png` показывает четыре варианта с одинаковыми камерой, материалами и неизменённой механикой:

1. Чистый исправленный корпус — текущая модель для печати.
2. Три несквозные канавки спереди слева внизу. Ширина 1 мм, длина 18 мм, глубина 0,35 мм; наклон в тон решётке динамика.
3. Три неглубокие канавки на каждой боковине в зоне хвата. Глубина до 0,35 мм, закруглённые концы. Лицевая панель остаётся чистой. **Этот вариант добавлен в STL.**
4. Сочетание вариантов 2 и 3.

Это CAD-рендеры реальных вариантов геометрии, а не нарисованные поверх фотографии линии. Габариты не увеличиваются, новые сквозные отверстия не появляются, функциональная решётка динамика не изменяется. Неглубокие канавки не требуют отдельных поддержек сами по себе; задняя крышка с переменной толщиной по-прежнему требует выбора ориентации/поддержек. Точность воспроизведения мелкого декора зависит от настроек печати.

`engraving-inside.png` — крупный вид исправленной гравировки с внутренней стороны передней крышки. Надпись читается слева направо при взгляде внутрь открытого корпуса.

`render_decor.py` создаёт только изображения и отчёт `checks.json`; печатные STL он не меняет. Выбранный вариант 3 воспроизводит основной генератор `../build_rev2.py`. Варианты 2 и 4 в печать не перенесены.
